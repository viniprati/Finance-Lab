## Finance-Lab

##  Sobre o Projeto

O **Finance-Lab** é um site educacional desenvolvido durante as aulas do **1º período do curso de Sistemas para Internet do Instituto Federal do Espírito Santo (IFES)**.

O projeto tem como objetivo apresentar informações básicas sobre diferentes modalidades de investimentos financeiros, auxiliando estudantes e iniciantes a compreenderem conceitos fundamentais do mercado financeiro de forma simples e acessível.

##  Objetivos

* Promover a educação financeira.
* Apresentar os principais tipos de investimentos disponíveis no mercado.
* Desenvolver habilidades práticas em desenvolvimento web.
* Aplicar conceitos de HTML, CSS e JavaScript aprendidos em sala de aula.
* Criar uma plataforma informativa com conteúdo organizado e de fácil compreensão.

##  Conteúdo Abordado

O site apresenta informações sobre:

* CDB (Certificado de Depósito Bancário)
* Fundos Imobiliários (FIIs)
* Tesouro Direto
* Poupança
* LCA (Letra de Crédito do Agronegócio)
* Investimento em Ações

Cada seção contém explicações sobre funcionamento, riscos, vantagens, desvantagens, exemplos práticos e resumos para facilitar o aprendizado dos usuários.

##  Tecnologias Utilizadas

* HTML5
* CSS3
* JavaScript
* Git
* GitHub


##  Projeto Acadêmico

Este projeto foi desenvolvido como atividade acadêmica da disciplina **Ferramentas para Trabalho Colaborativo**, ministrada pelo **Professor Bruno Clemente**, durante o **1º período do curso de Sistemas para Internet do IFES**.

O objetivo foi aplicar conceitos de desenvolvimento web, versionamento de código e trabalho colaborativo utilizando ferramentas amplamente empregadas no mercado de tecnologia.
