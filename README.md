#  Finance-Lab

##  Sobre o Projeto

O **Finance-Lab** é um site informativo sobre investimentos desenvolvido durante as aulas do **1º período do curso de Sistemas para Internet do Instituto Federal do Espírito Santo (IFES)**.

O projeto foi criado com o objetivo de aplicar os conhecimentos adquiridos em sala de aula nas áreas de desenvolvimento web, utilizando tecnologias fundamentais como **HTML**, **CSS** e **JavaScript**, além de promover a educação financeira por meio da disponibilização de conteúdos sobre investimentos.

##  Objetivos

- Apresentar conceitos básicos de investimentos.
- Divulgar informações sobre diferentes modalidades de aplicação financeira.
- Desenvolver habilidades práticas em desenvolvimento web.
- Aplicar conceitos de design, responsividade e experiência do usuário.

##  Tecnologias Utilizadas

- HTML5
- CSS3
- JavaScript
- Git e GitHub

##  Conteúdo do Site

O Finance-Lab aborda temas como:

- Introdução aos investimentos
- Renda Fixa
- Renda Variável
- Fundos de Investimento
- Educação Financeira
- Planejamento Financeiro

##  Desenvolvimento

Este projeto foi desenvolvido como atividade acadêmica da disciplina de Ferramentas para Trabalho Colaborativo - Prof. Bruno Clemente do **1º período de Sistemas para Internet - IFES**, servindo como prática dos conteúdos estudados durante a graduação.
